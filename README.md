# サクのきもち

トイプードルのサクの気持ちを、名古屋弁で教えてくれる家族用のアプリです。入口のページから、2つの遊び方を選びます。

- **声で きく:** なきごえの大きさと場面から、セリフを選びます。音はスマホの中だけで調べます。合言葉も、下の準備も要りません。
- **写真で よむ:** 顔の写真をAIが読み、セリフを吹き出しで出します。下の準備が要ります。準備の前は、用意されたセリフから選ぶ「AIなしモード」で動きます。

この下の手順は、主に「写真で よむ」のためのものです。

## 準備の全体像

次の順番で進めます。全部で30分から1時間ほどです。費用はかかりません。

| 順番 | やること | たとえると |
|---|---|---|
| 1 | AIを使う「鍵」をもらう | AIの部屋に入る鍵をもらう |
| 2 | 中継役(GAS)を作る | 写真を運ぶ係を雇う |
| 3 | アプリに中継役の住所を書く | アプリに係の住所を教える |
| 4 | アプリをインターネットに公開する | お店を開く |
| 5 | 家族に配る | 家族にお店の場所を伝える |

## 大事な約束

- 鍵(APIキー)は、他人に使われると困るパスワードのようなものです。**手順2のGoogleの画面以外には、どこにも貼らないでください。** shashin.js にも、GitHub にも、メモ帳のファイルにも置きません。特にOneDriveのフォルダに保存すると、写しがインターネット上に保管されます。
- 合言葉も同じです。登録するのは手順2のGoogleの画面だけです。
- Googleの画面で**支払い情報は登録しないでください。** 登録しなければ、回数の上限に達しても料金はかかりません。上限に達したときは、アプリが「AIなしモード」に切り替わるだけです。
- 公開すると、アプリの中身は誰でも見られます。合言葉で守られるのはAIを使う部分だけです。`koe.js` に書いてある家族の呼び名と、`saku.jpg` の写真も見られる点に気をつけてください。
- 無料枠では、送った写真をGoogleの担当者が確認したり、サービス改善に使ったりすることがあります。そのため、サク以外の人の顔や住所が写らないように撮ってください。

## 1. Gemini APIキーの取得方法(Google AI Studio)

Gemini API(ジェミニ エーピーアイ)は、Googleの写真を読めるAIを、ほかのアプリから呼び出す窓口です。APIキーは、その窓口を使うための鍵です。

1. パソコンのブラウザで [Google AI Studio](https://aistudio.google.com/) を開き、Googleアカウントでログインします。
2. 画面の中から「Get API key」または「APIキー」と書かれた所を押します。
3. 「APIキーを作成」を押します。プロジェクトを選ぶ画面が出たら、新しいものを作ります。
4. 表示された長い文字列をコピーします。次の手順ですぐ使います。

画面の言葉や場所は、Googleの更新で変わることがあります。

## 2. 中継役(GAS)を作る

GAS(ガス、Google Apps Script)は、Googleが無料で貸してくれるプログラム置き場です。ここで、スマホとAIの間で写真を受け渡します。

### プログラムを貼り付ける

1. [Google Apps Script](https://script.google.com/) を開き、「新しいプロジェクト」を押します。
2. 左上の「無題のプロジェクト」を押して、「サクの気持ち」に名前を変えます。
3. 最初から書いてある文字を全部消します。
4. このフォルダの `gas/Code.gs` をメモ帳で開き、中身を全部コピーして貼り付けます。
5. 上のフロッピーディスクの絵(保存)を押します。

### 鍵と合言葉を登録する

1. 左の歯車の絵(プロジェクトの設定)を押します。
2. 一番下の「スクリプト プロパティ」で「スクリプト プロパティを追加」を押します。
3. 次の2つを登録して、「スクリプト プロパティを保存」を押します。

| プロパティ(左の欄) | 値(右の欄) |
|---|---|
| `GEMINI_API_KEY` | 手順1でコピーした鍵 |
| `PASSPHRASE` | 家族で決めた合言葉 |

左の欄は、上の表の通りに半角の大文字で入れてください。合言葉は、お年寄りでも入れやすく、他人には当てにくいものにします。例えば、家族だけが分かる言葉を2つつなげると良いです。

### 設定を確かめる

1. 左の「<>」の絵(エディタ)に戻ります。
2. 上の関数を選ぶ欄で `checkSetup` を選び、「実行」を押します。
3. 初回だけ「承認が必要です」と出ます。自分のアカウントを選びます。
4. 「このアプリは Google で確認されていません」と出たら、「詳細」を押して、「サクの気持ち(安全ではないページ)に移動」を押し、「許可」を押します。自分で作ったプログラムなので、ここでは問題ありません。
5. 画面の下に「AIとの接続: 成功」と出れば準備完了です。

### ウェブアプリとして公開する

1. 右上の「デプロイ」を押し、「新しいデプロイ」を押します。デプロイは「公開する」という意味です。
2. 歯車の絵を押して、「ウェブアプリ」を選びます。
3. 次のように設定します。
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
4. 「デプロイ」を押します。
5. 表示された「ウェブアプリのURL」(`https://script.google.com/macros/s/` で始まるもの)をコピーします。

「全員」にしても、合言葉を知らない人はAIを使えません。

## 3. shashin.js にGASのURLを設定する

1. `shashin.js` をメモ帳で開きます。
2. 2行目を探します。

   ```js
   const GAS_URL = "ここにGASのURLを貼る";
   ```

3. `ここにGASのURLを貼る` の部分を、手順2でコピーしたURLに置きかえます。かぎかっこ `"` は消しません。

   ```js
   const GAS_URL = "https://script.google.com/macros/s/長い文字/exec";
   ```

4. 上書き保存します。

このURLは公開されても大丈夫です。合言葉がないと使えません。

## 4. GitHubリポジトリ作成とGitHub Pagesでの公開

GitHub(ギットハブ)は、プログラムを置いておく場所です。GitHub Pages(ギットハブ ページズ)は、その中身を無料でホームページとして公開する機能です。リポジトリは「プログラムを入れる箱」のことです。

**ここに置くものは、誰でも見られます。** 鍵と合言葉が入っていないことを、上の「大事な約束」でもう一度確かめてください。

1. [GitHub](https://github.com/) にアカウントを作り、ログインします。
2. 右上の「+」を押し、「New repository」を押します。
3. 「Repository name」に `saku-kimochi` と入れます。
4. 「Public」を選び、「Create repository」を押します。無料で公開するには Public を選びます。
5. 次の画面で「uploading an existing file」を押します。
6. このフォルダの中身を全部(`index.html` など、`icons` と `gas` のフォルダも)ドラッグして入れます。`test` のフォルダは入れなくても動きます。
7. 下の「Commit changes」を押します。
8. 上の「Settings」を押し、左の「Pages」を押します。
9. 「Branch」で `main` を選び、右の欄は `/(root)` のままで「Save」を押します。
10. 数分待ってからページを開き直すと、上に `https://自分の名前.github.io/saku-kimochi/` のようなURLが出ます。

このURLを開いて「写真で よむ」を押し、合言葉の画面が出れば公開は成功です。

## 5. 家族への配り方と「ホーム画面に追加」

LINEなどで、手順4のURLと合言葉を**別々のメッセージで**送ります。家族以外に転送しないよう伝えてください。

**必ず「ホーム画面に追加」を先にしてから、追加したアイコンで開いて合言葉を入れます。** iPhoneは、Safariとホーム画面で覚える場所が別なので、先に入れるともう一度聞かれます。

### iPhone(Safari)の場合

1. URLを **Safari** で開きます。LINEの中で開いたときは、右下のメニューから「デフォルトのブラウザで開く」を押します。
2. 画面の共有ボタン(四角から上に矢印が出ている絵)を押します。
3. 「ホーム画面に追加」を押します。見つからないときは、メニューを下に動かします。
4. 右上の「追加」を押します。
5. ホーム画面の「サクのきもち」を押して開き、「写真で よむ」を押して合言葉を入れます。

### Android(Chrome)の場合

1. URLを **Chrome** で開きます。
2. 右上の点が3つ並んだ絵を押します。
3. 「ホーム画面に追加」または「アプリをインストール」を押します。
4. 「追加」または「インストール」を押します。
5. ホーム画面の「サクのきもち」を押して開き、「写真で よむ」を押して合言葉を入れます。

## 6. 無料枠の上限やAIの名前が変わったとき

毎日「今日はAIがお休み」と出るようになったら、次を確認します。アプリ自体はAIなしモードで動き続けるので、急がなくても大丈夫です。

### 確認する場所

- 使えるAIの種類: [モデルの一覧](https://aistudio.google.com/docs/models)
- 無料で使えるAI: [料金のページ](https://aistudio.google.com/docs/pricing)
- 回数の上限: [Google AI Studio](https://aistudio.google.com/) の中の利用状況の画面

モデルとは、AIの種類のことです。無料枠の回数は変わることがあり、公式でも保証されていません。

### 原因の調べ方

1. GASの画面で `checkSetup` を実行します。
2. 下に出た結果に合わせて直します。

| 結果 | 意味 | 直し方 |
|---|---|---|
| 番号 429 | 回数の上限に達した | 次の日まで待つ |
| 番号 404 | AIの種類がなくなった | 下の手順でAIの種類を変える |
| 番号 400 や 403 | 鍵が無効 | 手順1で鍵を作り直し、`GEMINI_API_KEY` を更新する |

### AIの種類を変える手順

プログラムを書き直す必要はありません。

1. 料金のページで「Free of charge」(無料)と書かれていて、画像を読めるAIの名前を探します。`gemini-` で始まる名前です。
2. GASのプロジェクトの設定で、スクリプト プロパティに次を追加します。

   | プロパティ | 値 |
   |---|---|
   | `GEMINI_MODEL` | 探したAIの名前 |

3. 保存します。公開し直す必要はありません。

### Code.gs を書きかえたとき

スクリプト プロパティだけの変更なら不要ですが、`Code.gs` を変えたときは公開し直します。

1. 「デプロイ」を押し、「デプロイを管理」を押します。
2. 鉛筆の絵を押し、バージョンで「新バージョン」を選びます。
3. 「デプロイ」を押します。URLは変わりません。

## 7. セリフを追加・修正する

「声で きく」のセリフは `koe.js` の `LINES` に、場面と気持ちの大きさごとに入っています。

`shashin-lines.js` は、「写真で よむ」でAIがお休みのときに使うセリフ集です。

1. GitHubの画面で `shashin-lines.js` を押し、右上の鉛筆の絵を押します。
2. かぎかっこ `"` の内側を書きかえます。増やすときは1行まねして足します。

   ```js
   "うれしい": [
     "みんなの顔見たら、でらうれしいがね",
     "ここに新しいセリフを足す",
   ],
   ```

3. 「Commit changes」を押します。数分で反映されます。

守ること:

- かぎかっこ `"` と、行の最後のコンマ `,` を消さないでください。
- セリフは30文字以内にします。長いと写真が隠れます。
- 一番上の気持ちの名前(`"うれしい"` など)は変えないでください。AIの判定と共通で使っています。

うまく動かなくなったら、GitHubの「History」から前の状態を確認できます。困ったらClaude Codeに聞いてください。
